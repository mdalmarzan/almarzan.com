## 🖥️ পোর্টফোলিওর বিশেষত্ব (macOS UI Clone)

- Vanilla JavaScript দিয়ে তৈরি কাস্টম **Multi-Window Manager** — একাধিক উইন্ডো একসাথে খোলা, ড্র্যাগ করা এবং লেয়ার করে দেখানো যায়
- CSS ভেরিয়েবল ব্যবহার করে রিয়েল-টাইম **Light/Dark থিম** সুইচিং
- Background iframe প্রিজারভেশন (মিউজিক/মিডিয়া চলতে থাকে উইন্ডো বদলালেও)
- Apple-এর মতো গ্লাসমরফিজম (Glassmorphism) স্টাইলিং এবং UI ফিজিক্স
- মেনুবার, ডক, উইজেট, ওয়ালপেপার চেঞ্জার — বাস্তব macOS-এর প্রায় হুবহু অনুকরণ

## 🚀 উল্লেখযোগ্য প্রজেক্টসমূহ

### 1. macOS Web Environment (এই পোর্টফোলিও)
ব্রাউজারে সম্পূর্ণ ফাংশনাল macOS রেপ্লিকা — কাস্টম মাল্টি-উইন্ডো ম্যানেজার, থিম সুইচিং ও গ্লাসমরফিজম UI সহ।

### 2. [Peyebouste Marketing Platform](https://peyebouste.com) — *Apr–Jun 2026*
হাইতির একটি বিজ্ঞাপন এজেন্সির জন্য PHP ও Python দিয়ে তৈরি মার্কেটিং অটোমেশন প্ল্যাটফর্ম। Meta Ads API ইন্টিগ্রেশন, AI চ্যাটবট এবং অটোমেটেড রিপোর্টিং ফিচার রয়েছে।

### 3. AyitiBook E-Commerce Platform — *Jan 2026 – বর্তমান*
ডোমিনিকান রিপাবলিকের ক্লায়েন্টের জন্য বড় পরিসরের Laravel ভিত্তিক মার্কেটপ্লেস, যেখানে কাস্টমার, সেলার, অ্যাফিলিয়েট ও অ্যাডমিনদের জন্য আলাদা রোল-বেসড পোর্টাল আছে।

### 4. [Peelr Sticker Store](http://peelr.ddnsking.com)
Laravel দিয়ে বানানো স্টিকার বিক্রির ই-কমার্স সাইট, যেখানে JavaScript ও Python দিয়ে অটোমেটেড প্রোডাক্ট আপলোড পাইপলাইন আছে (ব্যাকগ্রাউন্ড রিমুভ, OpenCV দিয়ে মকআপ জেনারেশন)।

### 5. Service Management Platform (Multi-Tenant SaaS)
রিপেয়ার শপের জন্য বুকিং পোর্টাল, অ্যাডমিন ড্যাশবোর্ড এবং Capacitor দিয়ে বানানো মোবাইল অ্যাপ। Firebase Cloud Messaging (FCM) দিয়ে রিয়েল-টাইম নোটিফিকেশন।

### 6. [Vulcan-Pro Vulnerability Scanner](https://vulcanprodemo.vercel.app/) — *Jul–Sep 2025*
Nmap, Nikto, SQLmap, WhatWeb ইন্টিগ্রেট করা সিকিউরিটি স্ক্যানিং প্ল্যাটফর্ম, রিয়েল-টাইম ভিজ্যুয়ালাইজেশন ও PDF রিপোর্টিং সহ।

### 7. [Employee Management System](https://ems-ten-lovat.vercel.app/) — *Jun 2025*
কর্মচারীদের ডেটা, উপস্থিতি ও পেরোল ম্যানেজমেন্টের জন্য ফুল-স্ট্যাক অ্যাপ, CRUD ফাংশনালিটি ও রোল-বেসড অ্যাক্সেস কন্ট্রোল সহ।

### 8. [Vulcan Security Scanner](https://vulcandemo.vercel.app/)
